# Bitcoin Halving Countdown

A simple live countdown to Bitcoin's next halving at block 1,050,000.

- Current reward: 3.125 BTC
- After halving: 1.5625 BTC
- Date is estimated from live block height and a 10-minute average block time

## Run locally

Open `index.html` in a browser.

## GitHub Pages

Settings → Pages → Deploy from branch → `main` / root.
